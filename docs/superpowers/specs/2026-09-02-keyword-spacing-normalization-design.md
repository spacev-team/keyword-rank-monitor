# 키워드 붙여쓰기 정규화 설계

## 목표

모든 등록 키워드와 실제 검색 요청을 공백 없는 동일 문자열로 유지한다. 대시보드 표시명도 실제 검색어와 일치해야 한다.

## 현재 문제

전체 280개 키워드 중 공백이 있는 항목은 17개다. 공백 제거 후 12개는 이미 존재하는 붙여쓰기 키워드와 중복되며, 5개는 고유 키워드로 남는다: `airbnb`, `네이버부동산`, `피터팬의좋은방구하기`, `잠깐살집`, `모두를위한단기임대`.

`잠깐 살 집`과 `잠깐살집`은 네이버 광고 노출 결과가 달랐다. 표시 키워드와 사용자가 확인한 실제 검색어가 달라 순위 비교가 잘못됐다.

## 변경

1. 확장 브랜드 목록에서 띄어쓰기 변형 12개 생성을 제거한다. 붙여쓰기 형태는 이미 브랜드 또는 확장 브랜드 목록에 존재한다.
2. 경쟁사 목록의 공백 키워드 3개와 캠페인 목록의 공백 키워드 2개를 붙여쓰기로 변경한다.
3. `all_keywords()` 결과에 공백이 없고 키워드가 중복되지 않는다는 검증을 추가한다. 위반 시 수집 전에 실패시켜 잘못된 검색어가 배포되지 않게 한다.
4. 최종 목록은 중복 없는 268개다. 기존 SQLite 이력은 보존하며 다음 정상 수집부터 붙여쓰기 키워드가 새 시계열로 기록된다.

## 검증

- 전체 `all_keywords()` 268개에 공백과 중복이 없는지 확인한다.
- 그룹별 개수와 캠페인 5개 분류가 유지되는지 확인한다.
- 네이버 실수집에서 `잠깐살집`과 `모두를위한단기임대`의 광고 영역 상태를 확인한다. 예상값은 두 키워드 모두 `no_section`이다.
- 대시보드 내 키워드 표시는 붙여쓰기 형태와 일치해야 한다.
